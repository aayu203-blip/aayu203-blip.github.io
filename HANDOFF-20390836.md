## The Core Problem (Architecture)

The page currently loads **`ptc-components.js`** which renders a **different-looking** nav/footer (uses `#facc15` yellow, `#0f172a` dark-blue footer). Every other product page uses **`product-page.js`** which has the correct nav/footer.

`product-page.js` renders everything into `#root` div using a `P = {…}` data object. It can't just be swapped in without replacing the bespoke content.

**Solution:** Add a 3-line hook to `product-page.js`. If `window.PTC_CUSTOM_HERO` and `window.PTC_CUSTOM_SECTIONS` are defined as functions, use those instead of the default rendered sections. Existing pages define neither — zero impact on them.


## Notes

- The `PROD_SECS` array in product-page.js is module-scoped. The hook uses `splice()` to mutate it in place before `buildSidebar()` runs — this is safe because render() is called once synchronously.
- Gallery `currentImg` and `IMAGES` array must be declared as `var` (not `let/const`) since they're referenced by inline `onclick` handlers.
- The lightbox close and keyboard nav JS must remain in a `<script>` tag after `#root` since the DOM elements are injected by product-page.js at runtime.
- All FAQ, review, and related content is in PTC_CUSTOM_SECTIONS, not in the P object, since it's laid out with bespoke HTML rather than product-page.js card builders.
